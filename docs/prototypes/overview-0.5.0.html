dsh-stats 0.5.0 · UI 重排原型

项目总览重排

静态高保真原型，所有数字都是示例数据。可以直接操作：点列头排序、展开项目看会话、筛选项目、切换按日和全部、换日期、打开导出菜单和价格设置。面板宽度和数据状态在下面切换，蓝色数字对应页面底部的改动说明。

改动说明

  1. 1

    头部操作

    现状价格设置、刷新、CSV、JSON 是四个同样式的描边按钮，手机上头部折成三行。

    调整刷新和价格设置改为图标按钮，CSV 和 JSON 合进「导出」菜单；窄屏时头部保持两行。

  2. 2

    预估费用放在最前

    现状9 张等大卡片，费用排在最后；在 1440、1100 和手机宽度下分别排成 7+2、6+3 和 5 行。

    调整只留费用、Token、会话、LLM 时长 4 个主指标。费用字号最大，并显示与前一天的变化；估算说明收进 ⓘ 提示。

  3. 3

    次级指标

    现状轮/步、工具时长、首 token 各占一张卡，工具时长经常显示为 —。

    调整合成一行文字，没有数据的项不显示。

  4. 4

    项目筛选

    现状图例最多 50 个标签再加分页，项目多时占去半屏。

    调整改为「筛选项目」菜单，按钮上显示已隐藏数量；图例只保留在时间线。

  5. 5

    项目表格

    现状每行 11 列等权数字挤在右侧，左侧大片空白；排序靠下拉框加升降序按钮。

    调整6 列表格，点列头排序，费用列带占比条；轮/步、工具、首 token、tok/s 移到展开详情。

  6. 6

    单一滚动

    现状总览固定高度，项目列表和会话详情各自滚动，最多同时出现 3 条滚动条和 3 组分页。

    调整只保留面板主体一个滚动区，表头吸顶，分页只放在表格底部。

  7. 7

    待计价直达

    现状待计价模型要打开价格设置后在长面板里找，而且价格设置展开时会把统计内容推下去。

    调整点击任何「待计价」都会从侧边打开价格设置，并定位到对应模型。

  8. 8

    数据状态

    现状「宿主统计 · 已同步 · 更新时间」常驻一行，下面还有一条分割线。

    调整正常时只在头部显示状态点和时间；数据不完整或回退时才展开横幅，诊断收在折叠里。

  9. 整体

    窄屏

    现状项目卡片在手机上变成 5 列数字网格，会话详情横向挤压。

    调整每个项目两行：名称和费用一行，其余指标一行文字。切到「手机 390」查看。

  10. 整体

    键盘与读屏

    现状不能用 Esc 关闭，面板没有对话框语义，提示只能鼠标悬停打开。

    调整对话框语义加焦点还原，Esc 依次关闭菜单、抽屉和面板；视图切换用 tablist，列头带 aria-sort，提示可用键盘聚焦打开。

  11. 整体

    字号与颜色

    现状样式里有 18 种字号，最小 9.5px；费用橙色在白底上对比度不足。

    调整字号收敛为 11/12/13/15/20/28 六级；浅色主题下费用色加深，正文对比度达标。
